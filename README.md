##  Fitur Utama

### Autentikasi
- Login dengan validasi username/password (default: admin/123456)
- Remember Me untuk auto-login
- Session management dengan SharedPreferences
- Logout untuk clear session

### CRUD Mahasiswa
- **Create:** Form tambah mahasiswa dengan validasi
- **Read:** Tampil semua data dalam RecyclerView
- **Update:** Edit data mahasiswa yang sudah ada
- **Delete:** Hapus data dengan konfirmasi
- **Search:** Cari berdasarkan nama atau NIM

### Catatan Pribadi
- Catatan tersimpan per mahasiswa
- Auto-save ke Internal Storage
- Load otomatis saat buka detail
- File terpisah untuk setiap mahasiswa

---

## 📱 Cara Menjalankan Aplikasi

1. Clone repository ini
2. Buka project di Android Studio
3. Sync Gradle files (tunggu sampai selesai)
4. Build project (Build → Make Project)
5. Run ke emulator atau device Android (min SDK 23)

---

## 📝 Catatan Pengembangan

- **Default Login:** Username: `admin`, Password: `123456`
- **Database:** Tersimpan di `/data/data/com.example.studentcontactapp/databases/student_db`
- **Catatan:** Tersimpan di `/data/data/com.example.studentcontactapp/files/note_{id}.txt`
- **SharedPreferences:** Tersimpan di `/data/data/com.example.studentcontactapp/shared_prefs/auth_prefs.xml`
